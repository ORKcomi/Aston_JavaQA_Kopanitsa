# Домашнее задание 2.4

Проект рассчитан на Java 11. `Lesson24` запускает обе части задания, а `Main` вызывает ту же демонстрацию.

## Карта классов

| Класс или интерфейс | Назначение |
|---|---|
| `org.example.Lesson24`, `org.example.Main` | Точки входа в демонстрацию |
| `lesson24.animals.Animal` | Общие свойства, бег, плавание и счётчик животных |
| `lesson24.animals.Cat`, `Dog` | Ограничения движения и отдельные счётчики; у котов — аппетит и сытость |
| `lesson24.animals.Bowl` | Хранение еды, выдача полной порции и пополнение миски |
| `lesson24.figures.Shape` | Контракт фигуры и `default`-метод вывода характеристик |
| `lesson24.figures.Polygon` | Общий `default`-метод расчёта периметра многоугольника |
| `lesson24.figures.Circle`, `Rectangle`, `Triangle` | Площадь, периметр, цвет заливки и цвет границы |

Пакеты `lesson24.animals` и `lesson24.figures` находятся внутри `org.example`.

## Результаты демонстрации

- Кот бегает до 200 м и не плавает; собака бегает до 500 м и плавает до 10 м. Демонстрация проверяет допустимые дистанции и превышение ограничений.
- Создаются пять котов и две собаки: всего семь животных.
- После кормления из миски с 40 г еды сыты три кота, голодны два; остаток — 10 г. После добавления 50 г и повторного кормления все коты сыты, остаток — 10 г. При нехватке еды частичная порция не выдаётся.
- Круг радиуса 3: периметр 18.85, площадь 28.27. Прямоугольник 4 × 6: 20.00 и 24.00. Треугольник со сторонами 3, 4, 5: 12.00 и 6.00. Также выводятся цвета каждой фигуры.

Полный вывод: [docs/lesson-2.4-output.txt](docs/lesson-2.4-output.txt).

## Запуск

Установите JDK 11 и Maven; `JAVA_HOME` должен указывать на JDK 11. Выполните из корня проекта:

```text
mvn compile
java -cp target/classes org.example.Lesson24
```

Для запуска через `Main` используйте `java -cp target/classes org.example.Main`. Обе точки входа выводят одинаковый результат. Сборка проекта: `mvn package`.

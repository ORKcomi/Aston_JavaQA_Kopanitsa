# Домашнее задание к лекции 2.6 — коллекции

Java 11. Ветка `Lesson_2.6` содержит исходники только этого домашнего задания.

## Состав проекта

- `src/main/java/org/example/Main.java` — точка входа, запускающая оба задания.
- `src/main/java/org/example/Lesson26.java` — демонстрация и методы обработки студентов.
- `src/main/java/org/example/lesson26/Student.java` — имя, группа, курс и оценки по предметам.
- `src/main/java/org/example/lesson26/PhoneBook.java` — телефонный справочник.
- `docs/lesson-2.6-output.txt` — фактический вывод программы.

## Задание 1

Студенты хранятся в `LinkedHashSet<Student>`, оценки по предметам — в `Map<String, Integer>`.
Средний балл вычисляется с дробной частью; округление применяется только при печати.

- `removeUnderperformingStudents(Set<Student> students)` удаляет студентов со средним баллом < 3 через `Iterator.remove()`.
- `promoteStudents(Set<Student> students)` переводит на следующий курс только студентов со средним баллом >= 3.
- `printStudents(Set<Student> students, int course)` печатает имена студентов указанного курса.

В демонстрации из пяти студентов удаляются двое. Иван Петров и Анна Иванова переходят на 2-й курс, Мария Смирнова — на 3-й.
Анна со средним баллом ровно 3 остаётся в коллекции и переводится.
Изменение курса не нарушает поиск студента в `Set`: изменяемые поля не используются в `equals()` и `hashCode()`.

## Задание 2

Справочник использует `Map<String, Set<String>>` и хранит несколько номеров для одной фамилии.
`add(String surname, String phoneNumber)` добавляет запись, `get(String surname)` возвращает все её номера.
Номера из результата `get()` выводятся в `main()`.

Повтор одинаковой пары не создаёт дубликат. Для отсутствующей фамилии возвращается пустой набор.
Телефоны хранятся строками, с сохранением плюса и ведущих нулей. Регистр фамилии учитывается; крайние пробелы удаляются.
Результат поиска — неизменяемый снимок.
В примере у Иванова два номера, у Петрова один, Сидорова в справочнике нет.

## Запуск

В IntelliJ IDEA открыть `pom.xml` как проект, выбрать JDK 11 и запустить `org.example.Main`.
Через командную строку из папки проекта при установленных JDK 11 и Maven:

```text
mvn compile
java -Dfile.encoding=UTF-8 -cp target/classes org.example.Main
```

Отдельная точка входа: `org.example.Lesson26`.

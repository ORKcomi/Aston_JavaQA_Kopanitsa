# Aston Java QA — домашнее задание 2.6

Ветка: **Lesson_2.6**. Версия Java: **11**.

Оба задания запускаются из [Lesson26.java](src/main/java/org/example/Lesson26.java).
Класс `Main` также вызывает `Lesson26.main()`.

## Задание 1 — коллекция студентов

Класс [Student](src/main/java/org/example/lesson26/Student.java) содержит имя, группу, текущий курс и оценки по предметам.
Оценки хранятся в `Map<String, Integer>`: название предмета → оценка.
Средний балл вычисляется как арифметическое среднее с дробной частью; для сравнения с 3 округление не применяется.

В `Lesson26` реализованы отдельные методы:

| Метод | Действие |
|---|---|
| `removeUnderperformingStudents(Set<Student> students)` | Удаляет студентов со средним баллом строго меньше 3 |
| `promoteStudents(Set<Student> students)` | Повышает курс на единицу только студентам со средним баллом не ниже 3 |
| `printStudents(Set<Student> students, int course)` | Печатает имена студентов, обучающихся на указанном курсе |

В примере используется `LinkedHashSet<Student>`, сохраняющий порядок добавления.
Удаление выполняется через `Iterator.remove()`, чтобы безопасно изменять коллекцию во время обхода.
Перевод на следующий курс работает отдельно от удаления: студент со средним баллом ниже 3 не будет переведён и при самостоятельном вызове `promoteStudents()`.

`Student` использует стандартное сравнение объектов по экземплярам.
Изменение курса не нарушает поиск и удаление объекта в `HashSet` или `LinkedHashSet`;
разные студенты с одинаковыми именами могут присутствовать в коллекции.
Оценки копируются при создании студента и доступны через неизменяемую карту.
Не допускаются пустые имя/группа/названия предметов, курс меньше 1, отсутствие оценок, `null` и отрицательные оценки.
Крайние пробелы в текстовых полях удаляются; совпадающие после этого названия предметов отклоняются.

### Результат примера

| Студент | Средний балл при выводе | Результат |
|---|---:|---|
| Иван Петров | 4.00 | Переведён с 1-го на 2-й курс |
| Анна Иванова | 3.00 | Переведена с 1-го на 2-й курс |
| Пётр Сидоров | 2.67 | Удалён из коллекции |
| Мария Смирнова | 4.67 | Переведена со 2-го на 3-й курс |
| Алексей Кузнецов | 1.67 | Удалён из коллекции |

`printStudents(students, 2)` выводит Ивана Петрова и Анну Иванову, а `printStudents(students, 3)` — Марию Смирнову.

## Задание 2 — телефонный справочник

Класс [PhoneBook](src/main/java/org/example/lesson26/PhoneBook.java) хранит `Map<String, Set<String>>`:
фамилия → набор телефонных номеров.

- `add(String surname, String phoneNumber)` добавляет запись, сохраняя ранее добавленные номера этой фамилии.
- `get(String surname)` возвращает все найденные номера; в `main()` они выводятся в консоль.
- Для отсутствующей фамилии возвращается пустой набор.
- Повторное добавление одной пары «фамилия + номер» не создаёт дубликат.

`LinkedHashMap` и `LinkedHashSet` сохраняют порядок добавления.
Номера хранятся как строки: знак `+`, ведущие нули и внутренние разделители сохраняются.
Крайние пробелы удаляются, регистр фамилии учитывается. Пустые значения и `null` не допускаются.
`get()` возвращает неизменяемый снимок, через который нельзя изменить содержимое справочника.

В примере для Иванова выводятся оба номера, для Петрова — один, для отсутствующего Сидорова — `[]`.

## Проверка решения

Проверены компиляция на Java 11 без предупреждений и сборка Maven `package`.
Независимая проверка прошла 39 сценариев: средний балл и граница 3, удаление и перевод,
печать имён по курсу, сохранность объектов в `HashSet`, копирование оценок,
добавление и поиск всех номеров, дубликаты и защита результатов поиска от изменения.
Вывод `Main` совпадает с выводом `Lesson26`.

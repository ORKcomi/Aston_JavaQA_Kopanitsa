# Aston Java QA — домашнее задание 2.5

## Обработка массива и исключений

Метод `sumArray(String[][] array)` принимает двумерный строковый массив размером **4×4**:

1. Проверяет количество строк и длину каждой строки. Для любого другого размера выбрасывает `MyArraySizeException`.
2. Преобразует каждый элемент в `int` с помощью `Integer.parseInt()` и суммирует значения.
3. При ошибке преобразования выбрасывает `MyArrayDataException`, сохраняя исходный `NumberFormatException` как причину.

Собственные исключения находятся в пакете [lesson25](src/main/java/org/example/lesson25) и наследуются от `Exception`.
Они проверяемые: метод объявляет их в `throws`, а `main()` перехватывает отдельными блоками `catch`.

`MyArrayDataException` содержит ошибочное значение, индекс строки и индекс столбца.
В сообщении выводятся как индексы Java с нуля — например, `[1][2]`, — так и номера для чтения: строка 2, столбец 3.
Эти данные также доступны через `getRow()`, `getColumn()` и `getValue()`.

Размер всех строк проверяется до преобразования элементов.
Массив `null` или строка `null` приводят к `MyArraySizeException`.
Если форма массива корректна, `null` в отдельной ячейке, пустая строка, текст или число вне диапазона `int` приводят к `MyArrayDataException`.
Пробелы не удаляются: действует стандартное поведение `Integer.parseInt()`.
Входной массив не изменяется.

Каждый элемент преобразуется в `int`, а результат имеет тип `long`, чтобы избежать переполнения при сложении шестнадцати значений `int`.

## Демонстрация в main()

| Пример | Результат |
|---|---|
| Массив 4×4 со значениями от 1 до 16 | Сумма: **136** |
| Три строки вместо четырёх | Перехват `MyArraySizeException` |
| Четыре строки, одна из них длиной 3 | Перехват `MyArraySizeException` |
| Текст `ошибка` в ячейке `[1][2]` | Перехват `MyArrayDataException` с указанием ячейки и значения |
| Обращение к индексу 3 массива из трёх элементов | Генерация и перехват `ArrayIndexOutOfBoundsException` |

Каждый ошибочный пример обрабатывается, после чего программа продолжает работу.

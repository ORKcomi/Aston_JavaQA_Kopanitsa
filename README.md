# Домашнее задание 2.7 — JUnit 5

Ветка: `Lesson_7_junit_5`. Java 11. В проекте находится только задание 2.7.
Четыре программы одинаковы в обеих ветках; в этой ветке тесты написаны на **JUnit 5 5.13.4**.

## Программы

Исходники: `src/main/java/org/example/lesson27/`.

| Класс и метод | Результат |
|---|---|
| `Factorial.calculate(int number)` | Факториал числа; `0! = 1`, `5! = 120` |
| `TriangleArea.calculate(double a, double b, double c)` | Площадь треугольника по трём сторонам: формула Герона |
| `Calculator.add`, `subtract`, `multiply`, `divide` | Сложение, вычитание, умножение и деление двух целых чисел |
| `NumberComparator.compare(int first, int second)` | `-1`, если первое число меньше, `0`, если равно, `1`, если больше |

`org.example.Main` демонстрирует все четыре программы.
Фактический вывод: [docs/lesson-2.7-output.txt](docs/lesson-2.7-output.txt).

## Условия вычислений

- Факториал возвращается как `long`: разрешены числа от 0 до 20 включительно. Отрицательные числа и значения выше 20 вызывают `IllegalArgumentException`.
- Стороны треугольника должны быть положительными конечными числами и удовлетворять строгому неравенству треугольника. Ошибочные данные вызывают `IllegalArgumentException`. Используется обычная формула Герона в `double`: слишком большие или малые значения, при которых вычисление даёт бесконечность, `NaN` или нулевую площадь, также отклоняются.
- Сложение, вычитание и умножение принимают `int`, но возвращают `long`, чтобы не терять результат на границах `int`.
- Деление возвращает `double` с дробной частью; деление на ноль вызывает `ArithmeticException`.
- Сравнение поддерживает все значения `int`, включая минимальное и максимальное.

## Юнит-тесты

В `src/test/java/org/example/lesson27/` находятся четыре класса:
`FactorialTest`, `TriangleAreaTest`, `CalculatorTest`, `NumberComparatorTest`.

Используются `@ParameterizedTest`, `@CsvSource`, `@ValueSource`, `@MethodSource`. Проверяются обычные примеры, ноль, отрицательные числа, граничные значения, дробные результаты и исключения.
Для площади и деления сравнение выполняется с допустимой погрешностью.

Проверено на JDK 11: **68 тестов, 0 failures, 0 errors, 0 skipped**.
Фреймворк запускается через Maven Surefire 3.5.4. Результаты нового запуска появятся в `target/surefire-reports/`.

## Запуск

Нужны JDK 11 и Maven. Выполнить из корня проекта:

```text
mvn test
```

Запустить демонстрацию после компиляции:

```text
mvn compile
java -Dfile.encoding=UTF-8 -cp target/classes org.example.Main
```

В IntelliJ IDEA открыть `pom.xml`, выбрать JDK 11 и дождаться загрузки зависимостей Maven.
Для тестов запустить весь каталог `src/test/java` или отдельный тестовый класс; для демонстрации — `Main.main()`.

Документация фреймворка: [JUnit 5](https://docs.junit.org/5.13.4/user-guide/).
